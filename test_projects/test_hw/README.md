# test_hw

Generated by Hulotte framework.

## Build

```bash
./build.sh
```

Or manually:

```bash
mkdir build && cd build
cmake .. \
    -DSTREAMPU_ROOT=/home/cleroux/PROJECTS/hulotte/streampu \
    -DAFF3CT_ROOT=None \
    -DHULOTTE_ROOT=/home/cleroux/PROJECTS/hulotte
make -j
```

## Run

```bash
./build/test_hw
```


## Waveforms
